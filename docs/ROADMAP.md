# 开发路线

| 阶段 | 范围及验收 |
| --- | --- |
| M0-A 架构评审 | 已确认 ADR-001～ADR-027 及 UI 方向。 |
| M0-B 工程初始化 | 最小工程和正式文档已通过架构评审。以 `PLATFORMIO_CORE_DIR` 定位正式 CLI，迁移后的固件冷构建、Native 测试、分区及旧环境隔离复验均通过。 |
| M1 核心业务阶段 | 已完成正式验收。Core 和 Application 的两盆植物模拟闭环通过全部 79 项 Native 测试、Rev B 固件构建和分区校验。 |
| M1-A 模型与基础计算 | 已验收。C++17 业务模型、配置校验、静态就绪检查和标定换算已通过 Native 自验、Rev B 构建及独立源码审查。 |
| M1-B 灌溉规则与执行状态机 | 已正式验收。包含灌溉许可、额度、自动规则、停止和异常恢复，已通过 Native 自验、Rev B 构建及独立源码复审。 |
| M1-C 应用服务与 Native 闭环 | 已正式验收。修正 R08 跨日换绑冷却问题并通过最终独立源码复审。 |
| M2 设备基础 | 待开发。实现固件运行、驱动、独立控制任务、NVS、LittleFS、Wi-Fi、NTP。到货后尽早验证单模块，软件和实物分别验收。 |
| M3 Web 闭环 | 待开发。实现五个页面及 REST API，完成植物管理、标定、三种灌溉、历史曲线和 CSV 导出。验收实际可操作闭环。 |
| M4 实物联调 | 核验硬件，标定两盆植物，验证灌溉、安全停止、断网重连及断电恢复。建议进行至少 72 小时的有人值守连续运行。 |
| M5 `v0.1.0` | 两盆有人值守原型发布。交付正式构建产物、烧录及使用说明与验收结果，经授权创建正式语义化版本 Tag。 |
| M6 阳台及多盆 | 验证 10～15 米部署，扩展至 7～12 盆，核验信号、供水通道、水力条件及硬件保护。长距离模拟信号和 I2C 部署先实测。 |
| M7 正式家庭使用 | 完善防护、长期运行、维护及升级。通过稳定性和无人值守安全验收后再评估 `v1.0.0`。 |

## 首版延期范围

公网访问、远程通知、网页 OTA、RTC 接入、光照、缺水、漏水和流量检测、多水源与复杂阀门、分布式控制器、MQTT、Home Assistant、AI、植物知识库、天气预测、原生手机应用和企业级权限管理随需求与实际硬件阶段评估。
