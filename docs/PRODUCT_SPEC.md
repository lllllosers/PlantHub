# 产品规范

## 使用范围

封闭式家庭阳台约 10～15 米，水源位于一端，有市电及现有水桶。`v0.1.0` 面向两盆植物的有人值守原型，支持独立监测、分区及分组供水。通过可信家庭局域网使用手机、平板或电脑浏览器，必要功能由 ESP32 自治。扩展至 7～12 盆依赖实际监测及供水通道、管路和保护能力。

## 模型与关系

`Plant`、`SoilSensor`、`PumpChannel`、`IrrigationZone`、`IrrigationGroup`、`IrrigationRule`、`SensorReading`、`IrrigationRecord`、`SystemConfig` 是规划模型。分区是最小独立灌水单元，灌溉组是分区的逻辑集合。

- 一盆植物最多绑定一个土壤探头，可以暂不绑定。一个探头最多服务一盆植物。
- 一盆植物最多属于一个分区。分区可以服务多盆植物，并指定代表性探头作为智能判断依据。每个分区绑定一个独立水泵通道，水泵通道最多绑定一个分区。
- 一个分区可加入多个组，组按分区逐一执行。首版默认水泵互斥。
- 两盆原型分别绑定探头 1、2 和分区 1、2，各分区使用同序号的水泵通道。物理连接见 [Rev B 硬件基线](../hardware/rev-b/README.md)。系统容量取决于可用硬件通道。

## 灌溉规则

- 手动、定时、智能灌溉使用 [同一执行入口](ARCHITECTURE.md#灌溉执行)，均受最长运行时间、单次限额、每日限额和互斥保护。正常按量执行前须具有有效时间和可靠的关键状态持久化能力。
- 分区的自动模式为关闭、定时或智能，默认关闭。手动请求仍可独立受理。智能模式建议默认连续三次有效低湿度读数触发固定剂量，冷却后重新采集和判断。单轮到达固定剂量即停止。
- 启泵前持久化执行凭据并保守预留额度。每日限额计入三种模式，重启或时钟回拨后保留已用额度。意外断电且执行量无法确认时，按预留额度记账并记录结果未知，重启后不续灌。
- 上电默认停泵，非阻塞运行，设置独立停止时限、看门狗与故障处理。手动停止取消待执行任务，暂停自动灌溉，等待用户恢复。软件保护须与后续硬件保护一同验收。

## 采集与标定

- 土壤相对湿度采用每个探头独立的干湿两点标定，公式为 `(raw - dryRaw) / (wetRaw - dryRaw) × 100`，兼容正向和反向响应。显示限制在 0～100%，保留原始量及超范围状态。ADC 等硬件条件改变后复核标定。未标定、无效、采集失败和过期数据使用 `null` 或明确状态，均禁止触发智能灌溉。
- 空气 VPD 采用 `es = 0.6108 × exp(17.27 × T / (T + 237.3))`，`VPD = es × (1 - RH / 100)`。温度单位为 °C，相对湿度单位为 %，VPD 单位为 kPa，仅用于监测。
- 各路分别标定水泵，流量为 `实际收集量(mL) / 运行时间(s) × 60`，目标时长为 `目标水量(mL) / 标定流量(mL/min) × 60`。安装后按实际管路、扬程和出水条件重新标定。记录目标水量、标定流量、实际运行时长和估算水量。GPIO 状态仅表示控制输出，出水和估算水量须分别表达。

## 时间与历史

运行时长、冷却和超时使用单调时间。定时、历史及每日额度使用日期时间，内部使用 UTC 时间戳，界面按系统时区显示。NTP 校时有效且设备持续供电时，断网可沿用内部时钟。无有效时间时暂停自动灌溉，仅允许明确进入有人值守的限时设备调试模式。错过的定时任务不补执行，时钟回拨时按凭据去重。

| 参数 | 默认值 |
| --- | --- |
| 传感器采集 | 60 秒 |
| 仪表盘刷新 | 5 秒 |
| 历史采样写入 | 5 分钟 |
| 监测历史保留 | 14 天 |
| 灌溉历史保留 | 90 天，受容量约束 |
| 历史格式及清理 | 按日追加 CSV，删除过期完整日文件 |
| 维护空间 | 约 20%，后续按实测文件评估 |

历史写入失败时提示故障并保留文件系统。关键灌溉状态写入失败时拒绝新的正常灌溉请求。配置持久化详见 [存储职责](ARCHITECTURE.md#存储与发布)。

## 访问与首版范围

首版单管理员，使用基本访问密码。控制和配置需要认证，实施必要的跨站请求保护、参数校验和请求大小限制。设备以 STA 接入家庭网络，必要时使用带密码的临时 AP 配网，完成后关闭 AP。延期项目见 [开发路线](ROADMAP.md)。

## UI 设计基线

PlantHub 中文名为家庭智慧灌溉系统。界面采用绿色圆角方形和白色幼苗标志，主色为低饱和度自然绿，背景为白色及浅灰色。使用简体中文、轻量卡片和手机优先的响应式布局，兼顾平板与电脑。绿色表示正常，橙色提示警告，红色表示异常和危险操作。

### 首版五个页面

| 页面 | 内容 |
| --- | --- |
| 首页仪表盘 | 空气温度、空气相对湿度、VPD、植物湿度卡片、设备运行状态、快捷灌溉及今日灌溉统计 |
| 植物管理 | 新增、编辑及停用植物，绑定探头、关联分区、独立湿度标定 |
| 灌溉管理 | 水泵通道和流量标定、分区和分组、手动及自动模式、运行倒计时、估算灌水量、停止灌溉 |
| 历史记录 | 空气温湿度、VPD 和土壤相对湿度曲线，灌溉记录及 CSV 导出 |
| 系统设置 | 网络、时间、采集间隔、历史保留、配置备份、系统信息和诊断 |

全局提供停止灌溉入口。设备在线、传感器有效性和自动灌溉状态分别显示。使用真实空状态，无效值保留其状态，图表缺测时断线。只展示已有采集能力支持的指标。植物使用轻量 SVG 图标。HTML、CSS、模块化 JavaScript 与图表资源均从设备本地加载。交互页面由 M3 实施，延期功能随能力交付。
