## 固件交接
- ESP32-S3 N16R8；I2C SDA GPIO8 / SCL GPIO9，初始 100 kHz。
- ADS1115 0x48（ADDR 接地），A0/A1 对应探头 1/2，A2/A3 预留；GY-SHT31 通常 0x44，以扫描为准。
- GPIO4/5 对应泵 1/2；GPIO10/11 预留泵 3/4；GPIO6/7 预留缺水/漏水。有效电平及上电状态待实测。
- DS3231（0x68）预留，当前不安装、不接线。无有效时间时暂停自动灌溉。
- 主控 USB 5V，传感器 3.3V，动力 12V；两脚开关串接动力正极；动力不经过面包板。信号地与动力地分开以驱动板有效隔离为前提。

## 待核实
